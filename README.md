# giftokeep-site

Public website for **Giftokeep**, the iPhone gift planner: home, support and privacy pages in English and German, served by GitHub Pages from `docs/`.

The app's source is in a separate private repository. App Store Connect links here for the privacy policy and support URLs, so these pages can be updated without resubmitting the app.

**Keep this true:** the privacy policy describes what the shipped app does. When the app gains photos, Contacts access or iCloud sync, update both languages *before* that version ships.
