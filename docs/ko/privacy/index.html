개인정보 처리방침

Giftokeep은 선물, 사람, 계획을 사용자의 iPhone에 보관합니다. 개인 데이터를 수집하거나 저장하거나 개발자에게 전송하지 않습니다.

최종 업데이트: 2026년 10월 4일

Giftokeep이 저장하는 정보와 저장 위치

사용자가 추가한 사람, 기록한 선물(준 선물과 받은 선물), 가격, 계기, 감사 인사 상태, 아이디어, 이벤트 계획과 예산은 사용자의 기기에 있는 앱 자체 저장 공간에만 저장됩니다. 업로드되는 것은 없습니다. Giftokeep 서버는 존재하지 않습니다.

iCloud 백업이나 컴퓨터로 iPhone을 백업하면, 이 데이터는 다른 모든 앱의 데이터와 마찬가지로 Apple의 약관에 따라 해당 백업에 포함됩니다.

계정, 분석, 추적이 없습니다

로그인이 없습니다. Giftokeep에는 분석 도구도, 광고도, 데이터를 수집하는 서드파티 코드도 없습니다. 앱이나 웹사이트를 넘나들며 사용자를 추적하지 않습니다.

가격 추정

Giftokeep이 가격을 제안할 때는 사용자의 기기에서 계산합니다. 이전에 입력한 가격이나, 선물을 구매한 지역의 일반적인 가격이 담긴 내장 표를 바탕으로 합니다. 추정을 위해 선물 이름이 어디로든 전송되는 일은 없습니다.

구매

한 번만 구매하는 잠금 해제는 Apple이 App Store를 통해 판매하고 처리합니다. 가격을 보여 주고 구매를 완료하기 위해 Giftokeep은 App Store에 요청하며, Apple은 앱에 잠금 해제 구매 여부만 알려 줍니다. Giftokeep은 결제 정보나 Apple 계정을 볼 수 없으며, 선물·사람·계획 데이터를 전송하지 않습니다.

사용자의 지역

통화와 가격 추정에 사용되는, 사용자가 구매 지역으로 선택한 값은 iOS의 표준 설정 저장 공간을 통해 사용자의 기기에 저장됩니다.

권한

이 버전의 Giftokeep은 어떤 권한도 요청하지 않습니다. 연락처, 사진, 위치, 알림 모두 사용하지 않습니다. 이후 버전에서 권한이 필요해지면 먼저 사용자에게 요청하며, 해당 버전이 출시되기 전에 이 방침에 사용 목적을 안내하겠습니다.

알림

이후 버전에서 미리 알림이 제공되더라도, 선물을 받을 사람이 잠금 화면을 볼 수 있으므로 선물 이름 자체는 절대 표시되지 않습니다.

어린이

Giftokeep은 어린이를 포함해 누구에게서도 데이터를 수집하지 않습니다.

데이터 삭제

앱에서 사람, 선물, 직접 만든 이벤트를 삭제할 수 있습니다(선물은 길게 누르고, 이벤트나 사람은 살짝 밀어서 삭제). 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다.
