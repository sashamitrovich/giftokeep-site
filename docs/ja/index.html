すべての贈り物を、心を込めて包み、大切に残す。

イベントごとに、あげたもの・もらったものを覚えておきましょう。予算を決めてクリスマスの計画を立て、アイデアは一年中保存できます。

同じ贈り物を二度と贈らない。 一人ひとりに、あげたものともらったものの両面の履歴があります。
贈り物の記録は4タップで。 贈り物は、タップできる言葉でできた一文です。相手、贈り物、機会、目安の価格があらかじめ入力されています。
予算内で、すべてのイベントを計画。 クリスマスをはじめ、お住まいの地域のギフトの祝日があらかじめ用意されていて、ご自身のイベントも追加できます。
最初からプライベート。 すべてのデータはiPhoneの中だけに保存されます。アカウント不要、分析なし、トラッキングなし。
